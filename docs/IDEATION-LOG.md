# Ideation log

After the MVP, three ideation loops each picked features from
`docs/ROADMAP.md`, built them with up to four parallel agents, and recorded
the outcome here.

## Loop 1: live events and deeper signals (2026-11-03)

Theme: the MVP polls files and system APIs. This loop adds sources that are
event-driven or that explain the texture of a day.

Picked:
1. **Claude Code hooks** (`molly hook` + `POST /event`). Zero-lag tool-call
   and session counters, plus a generic event endpoint any script can use.
2. **Input intensity, clipboard rhythm, connected hardware.** Three small
   collectors: key/click counts per minute (opt-in, Accessibility), copy
   frequency and content type (never content), displays/USB/audio devices.
3. **Flow detection and context-switch ledger** as Prometheus recording rules,
   plus a weekly review dashboard and agent-ROI panels.
4. **Sleep/boot forensics and build activity.** `pmset -g log` and `last
   reboot` parsed into counters so gaps are explainable; compiler/build
   processes and Xcode DerivedData logs as build metrics; browser tab counts
   (opt-in AppleScript).

Outcome: all four shipped and merged. New collectors `events`, `input`
(off by default), `clipboard`, `hardware`, `power`, `builds`, `tabs` (off by
default); `molly hook` with `snippet`/`install`/`uninstall`; `POST /event`;
twelve new recording rules (flow state, interruptions, agent ROI, day shape);
a seventh dashboard "Molly / Week"; annotations for commits, meetings and
screen lock on Overview, Focus and Week. Tests went from 148 to 198. The
first three subagents (running on a different model) refused to edit without
your in-person confirmation of the global CLAUDE.md rule, so those tasks were
re-run as forks of this session, which carry your original instruction.

## Loop 2: agents that look at the data (2026-11-03)

Theme: Molly now records a lot. This loop makes it explain itself.

Picked:
1. **`molly insights`**: a daily (and weekly) narrative plus three concrete
   recommendations, generated by Claude from a filtered digest of the day's
   metrics; served at `/insights/latest` and written to the data folder.
2. **`molly mcp`**: a stdio MCP server so any agent can query Molly's
   Prometheus history (PromQL, day summary, current context, metric catalog).
3. **Privacy audit** (`/privacy`, `molly privacy`): every label dimension,
   its policy, and how many values were folded to `other`/`redacted`; plus
   anomaly alert rules and an alerts panel on the Health dashboard.
4. **`molly tune`**: reads the live registry (series per family, label
   cardinality, collector errors and durations) and proposes config changes
   as a diff. Rules-based, with an optional Claude pass.

Outcome: all four shipped and merged. `molly insights` (49-query digest,
Claude API or `claude` CLI backend, cached daily/weekly Markdown, served at
`/insights/latest`, optional scheduled `insights` collector, off by default);
`molly mcp` with five read-only tools (`query_metrics`, `list_metrics`,
`day_summary`, `current_context`, `collector_status`); `/privacy` and
`molly privacy` auditing all 16 label dimensions with decision counters;
nine informational anomaly alerts and an Alerts row on the Health dashboard;
`molly tune` with nine rules, `/stats`, registry-size self metrics, and a
`--apply` that patches config with a backup. Tests went from 198 to 262.
One real narrative was generated through the CLI backend to prove the path;
its headline finding was that code is being produced faster than it can be
reviewed.

## Loop 3: product and operations (planned)

Theme: make Molly something you install once and forget, and give the
`projects` collector the signal it is missing.

Picked:
1. **Shell cwd hook**: a one-line zsh/bash `precmd` that posts the working
   directory to `POST /event` (source `shell`), so `projects` finally gets the
   shell signal; `molly shell-hook snippet|install|uninstall`.
2. **Launch at login and packaging polish**: SMAppService when running from
   Molly.app, an app icon, `molly status` in the menu bar, and a
   `make dist` zip with a checksum.
3. **Media and window titles (opt-in)**: now-playing via AppleScript for
   Music and Spotify (track labels behind a policy), and window titles behind
   a `titles` policy with Screen Recording permission, hashed by default.
4. **Backup, export and remote**: `molly export` Prometheus snapshot to a
   tarball, `molly prune`, remote_write and Grafana Cloud docs, a fleet
   dashboard variable for multiple hosts.
